# Сайт-визитка — Денис Шандалин

Техническая выжимка сессии перед очисткой контекста. Обновлено: 2026-08-31.

## 1. Архитектурные решения

- **Самодостаточные файлы**, без сборки, без фреймворков, ванильный JS только для
  reveal-анимаций. Требование заказчика: файл открывается офлайн. Страниц две, они живут
  параллельно и намеренно сделаны в разных дизайн-системах — выбор главной отложен:
  - `index.html` — референс **Dylanbrouwer** (описан ниже);
  - `dala.html` — референс **Dala**, добавлена 2026-08-31 вместе с портретом `photo.jpg`.
- **Дизайн-система** — взята буквально с referero: карточка **Dylanbrouwer**
  (`styles.refero.design/style/b1e82907-...`), выбрана из трёх сравненных (Thomas Vimare,
  David Kirschberg, Dylanbrouwer) как единственная, рассчитанная на плотный контент
  (моно-подписи, волосяные линии, нумерация) — остальные две держатся на пустом пространстве
  и не годятся для блока с болями/кейсами.
  - Токены цвета: `--bg:#0d0d0f`, `--text:#f2f1ef`, `--muted:#8b8b88`, `--dim:#66665f`,
    `--ember:#ff6436` (единственный акцент, используется только как пунктуация — точки,
    маркеры, заливка кнопки при hover, никогда как фон блока).
  - Шрифты: `IBM Plex Mono` (моно-подписи/метаданные), `Inter` (тело), `Inter Tight`
    (подзаголовки, телефон), `Oswald 700 uppercase` (имя в шапке — выбрано пользователем
    из 5 вариантов на отдельной сравнительной странице `name-options.html`, которая после
    выбора удалена из репозитория).
  - **Motion-токены взяты буквально из DESIGN.md референса**, не придуманы:
    `--enter: cubic-bezier(.32,.72,0,1)`, `--exit: cubic-bezier(.19,1,.22,1)`,
    длительности `.3s/.5s/.72s`. Анимируются только `transform`, `opacity`,
    `background-position` — никогда `width/height` (реёлоу).
- **Дизайн-система `dala.html`** — карточка **Dala**
  (`styles.refero.design/style/e5f5f8cf-e68d-4ed1-bbf5-6b67569af648`), выбрана
  пользователем. Устроена принципиально иначе, чем Dylanbrouwer: иерархия строится
  **масштабом, а не насыщенностью**.
  - Цвет: `--void:#000000` (строго чистый чёрный), `--bone:#ffffff`, `--ash:#9a9a9a`,
    `--silver:#bdbdbd`, `--iris:#8052ff` (заливка кнопок и нумерация), `--saffron:#ffb829`
    (метки-надзаголовки и акцентные ссылки).
  - Типографика: заголовки **только весом 400**, тело **только весом 200** (18px),
    трекинг −0.04em от 42px и выше. Шкала 113/78/48/42/27/24/18/14/12 px.
  - Сетка: базовый юнит 6px, `max-width:1280px`, зазор секций 60–120px, скругления 24px,
    кнопки-пилюли. **Никаких карточек с рамками и тенями**, никаких градиентов на
    элементах интерфейса.
  - PPNeueMontreal из оригинала — коммерческий шрифт; сам DESIGN.md референса указывает
    запасным **Inter**, поэтому взят он (нужные веса 200/400/600/700 есть).
  - Правило «одна залитая кнопка на экран» соблюдено так: залиты только «Позвонить» в
    hero и «WhatsApp» в контактах (они в разных экранах), остальные пять каналов —
    контурные пилюли.
- **`prefers-reduced-motion`** — полное отключение движения явными `animation:none` для
  бесконечных анимаций (пульс точки, переливание имени), а не только обнулением
  `animation-duration` через wildcard (бесконечный цикл на 0.01ms всё равно тикает).

## 2. Результаты исследований

**Сработало:**
- Формат DESIGN.md на Refero даёт готовые числовые токены (hex+роль, точная типошкала,
  motion-кривые) — можно переносить в CSS почти дословно, не интерпретируя описания.
- MAX-мессенджер **не имеет диплинка по номеру телефона** — только `max.ru/username` или
  `max.ru/u/<токен>` (подтверждено WebFetch на messangermax.ru). Кнопка ждала персональную
  ссылку от пользователя.
- Позиционная развёртка reveal-блоков (проявлять всё, у чего `top < 0.88 * innerHeight`,
  включая уехавшее вверх) — правильное **действие**. Но её мало: нужен ещё надёжный
  **сигнал**, когда её запускать, см. раздел про три источника ниже.
- Принудительный reflow (`void document.body.offsetWidth`) надёжнее `requestAnimationFrame`
  для первого рендера — rAF не срабатывает в панели предпросмотра/фоновых вкладках.

**Не сработало / ограничения найдены:**
- Карточки Refero **не содержат motion-токенов** почти никогда (проверено целенаправленным
  поиском на 6 карточках, включая Jitter — инструмент для моушн-дизайна). Кривые для этого
  сайта — редкое исключение (у Dylanbrouwer они есть).
- **Reveal нельзя вешать на один источник событий — замерено на `dala.html` 2026-08-31,
  каждый из трёх поодиночке дырявый:**
  - `scroll` — в панели предпросмотра **не приходит вообще**: свежий слушатель поймал
    ноль событий при прокрутке на всю высоту страницы. На одних слушателях вся страница
    ниже первого экрана осталась бы невидимой (именно это и произошло при первой сборке).
  - `IntersectionObserver` — во-первых, при резком прыжке сообщает **только** о том, что
    оказалось в кадре на месте приземления: прыжок в самый низ дал 6 срабатываний из 32,
    пролетевшее мимо не отмечается никогда. Во-вторых, доставка колбэков привязана к
    циклу отрисовки — там же, где не работает `requestAnimationFrame`, молчит и он
    (`firedOnAttach: 0` при заторможенной отрисовке панели).
  - Таймер — единственное, что тикает всегда, но сам по себе не знает про прокрутку.
  Рабочая связка в `dala.html`: наблюдаем **секции** (они замощают страницу без разрывов,
  поэтому любой сдвиг прокрутки кого-то вводит/выводит из кадра) + `scroll`/`resize` +
  страховочный `setInterval(250ms)`, который выходит по сравнению `scrollY`, если
  прокрутка не двигалась. Все три источника снимаются сами, когда проявлять нечего.
  Это же актуально не только для панели: ссылку открывают во встроенных браузерах
  Telegram/MAX/WhatsApp, где такие же особенности вполне реальны.
  **В `index.html` эта страховка не добавлена** — там остались только `scroll`/`resize`.
- **Порог развёртки нужно снимать у самого низа страницы.** Поймано уже на живом сайте:
  при `scrollY == maxY` элементы, попавшие в нижние 12% экрана, не проявлялись никогда —
  докручивать некуда, новых событий не будет. На высоком окне туда попадали **телефон и
  все кнопки мессенджеров** (34 из 37 блоков), то есть ровно то, ради чего визитку
  открывают. Лечится проверкой `scrollY + innerHeight >= scrollHeight - 2` → порог
  `Infinity`. Проверять именно на высоком окне: на 900px баг не воспроизводится.
- Специфичность легко перебивает токены дизайн-системы: правило `.item p` (0,2,0)
  перекрывало `.label-iris` (0,1,0), и фиолетовая нумерация «01» молча становилась
  обычным серым абзацем 18px. Лечится `:not(.label)`. Проверять роли типографики не
  глазами, а `getComputedStyle` — цвет/кегль/вес разом.
- Скриншоты в панели предпросмотра иногда показывают ложное горизонтальное обрезание текста
  (визуальный артефакт масштабирования скриншота) — не доверять скриншоту вслепую, проверять
  через `document.documentElement.scrollWidth > window.innerWidth` и `getBoundingClientRect()`.
  Хуже того: при прокрутке панель отдаёт частично собранные и устаревшие кадры (чёрный
  экран, куски из разных мест страницы, пропавшее фото) и сбрасывает эмуляцию размера
  после ввода. Надёжно снимается только **первый экран сразу после `navigate`**; для
  остального ставить `resize_window` на высоту всей страницы либо проверять геометрию
  через `getBoundingClientRect`/`getComputedStyle`, а не глазами.
- Ссылка на MAX из личного файла пользователя отличается от той, что дал в чате.
  Разобрано 2026-08-31: в `Личное_досье_Денис_Шандалин.md` лежит `max.ru/join/...` —
  это **приглашение в группу**, а не личный профиль, поэтому расхождения нет.
  На обеих страницах стоит личная ссылка `max.ru/u/...` из чата — она и верна.
