# Сайт-визитка — Денис Шандалин

Техническая выжимка сессии перед очисткой контекста. Обновлено: 2026-08-31.

## 1. Архитектурные решения

- **Один файл** `index.html` (559 строк), без сборки, без фреймворков, ванильный JS только
  для reveal-анимаций. Требование заказчика: самодостаточный файл, открывается офлайн.
- **Дизайн-система** — взята буквально с referero: карточка **Dylanbrouwer**
  (`styles.refero.design/style/b1e82907-...`), выбрана из трёх сравненных (Thomas Vimare,
  David Kirschberg, Dylanbrouwer) как единственная, рассчитанная на плотный контент
  (моно-подписи, волосяные линии, нумерация) — остальные две держатся на пустом пространстве
  и не годятся для блока с болями/кейсами.
  - Токены цвета: `--bg:#0d0d0f`, `--text:#f2f1ef`, `--muted:#8b8b88`, `--dim:#66665f`,
    `--ember:#ff6436` (единственный акцент, используется только как пунктуация — точки,
    маркеры, заливка кнопки при hover, никогда как фон блока).
  - Шрифты: `IBM Plex Mono` (моно-подписи/метаданные), `Inter` (тело), `Inter Tight`
    (подзаголовки, телефон), `Oswald 700 uppercase` (имя в шапке — выбрано пользователем
    из 5 вариантов на отдельной сравнительной странице `name-options.html`, которая после
    выбора удалена из репозитория).
  - **Motion-токены взяты буквально из DESIGN.md референса**, не придуманы:
    `--enter: cubic-bezier(.32,.72,0,1)`, `--exit: cubic-bezier(.19,1,.22,1)`,
    длительности `.3s/.5s/.72s`. Анимируются только `transform`, `opacity`,
    `background-position` — никогда `width/height` (реёлоу).
- **`prefers-reduced-motion`** — полное отключение движения явными `animation:none` для
  бесконечных анимаций (пульс точки, переливание имени), а не только обнулением
  `animation-duration` через wildcard (бесконечный цикл на 0.01ms всё равно тикает).

## 2. Результаты исследований

**Сработало:**
- Формат DESIGN.md на Refero даёт готовые числовые токены (hex+роль, точная типошкала,
  motion-кривые) — можно переносить в CSS почти дословно, не интерпретируя описания.
- MAX-мессенджер **не имеет диплинка по номеру телефона** — только `max.ru/username` или
  `max.ru/u/<токен>` (подтверждено WebFetch на messangermax.ru). Кнопка ждала персональную
  ссылку от пользователя.
- Позиционная развёртка reveal-блоков по прокрутке (polling on scroll/resize + fallback)
  надёжнее `IntersectionObserver` — наблюдатель пропускает элементы при резком прыжке
  прокрутки (`Ctrl+End`, восстановление позиции).
- Принудительный reflow (`void document.body.offsetWidth`) надёжнее `requestAnimationFrame`
  для первого рендера — rAF не срабатывает в панели предпросмотра/фоновых вкладках.

**Не сработало / ограничения найдены:**
- Карточки Refero **не содержат motion-токенов** почти никогда (проверено целенаправленным
  поиском на 6 карточках, включая Jitter — инструмент для моушн-дизайна). Кривые для этого
  сайта — редкое исключение (у Dylanbrouwer они есть).
- Скриншоты в панели предпросмотра иногда показывают ложное горизонтальное обрезание текста
  (визуальный артефакт масштабирования скриншота) — не доверять скриншоту вслепую, проверять
  через `document.documentElement.scrollWidth > window.innerWidth` и `getBoundingClientRect()`.
- Ссылка на MAX из личного файла пользователя (`.../f9LHodD0cOJg2id9L6ttFrPfty17...`)
  отличается от той, что дал в чате (`.../f9LHodD0cOKMLjpP93TXn8BDP9J3eHp-b2-.../`)
  — **на сайте сейчас стоит ссылка из чата**, расхождение не разрешено.

## 3. Текущий статус

- Репозиторий: `github.com/Smit1980/shandalin-vizitka` — **публичный** (сделан публичным
  по явному согласию пользователя ради GitHub Pages).
- **Сайт живой**: https://smit1980.github.io/shandalin-vizitka/ — Pages включён с ветки
  `main`, root `/`, статус сборки `built`, проверен вручную на 375px (без переполнения).
- Последний коммит: `a48de6e` «Ярче имя, секция «Кейсы», расширенное «Обо мне»» — запушен
  в `origin/main`, рабочее дерево чистое, расхождений с origin нет.
- Локальный сервер предпросмотра: `python -m http.server 8000`, конфиг в
  `.claude/launch.json` (имя `vizitka`), может быть ещё поднят в фоне с прошлой сессии —
  проверить `preview_list` перед повторным запуском.
- Структура секций на странице (нумерация в моно-подписях): `01 Обо мне` →
  `02 Кейсы` (Клуб «ИИ в образованИИ», Корпорация «Алмаз-Антей») → `03 С чем приходят`
  (боли рынка ИИ-внедрения, со ссылками на MIT/Forbes и обзоры рынка РФ) →
  `04 Чем могу быть полезен` → `05 Контакты` (тел./WhatsApp/MAX/Telegram).
- Контент кейсов взят из личных файлов пользователя (`H:\Мой диск\Все про меня\...`),
  кейс «Алмаз-Антей» намеренно оставлен кратким/общим — источник содержал только одну
  строку упоминания, без деталей роли/масштаба/результата, домысливать не стали.
